CSRF Attack Breakdown

This page submits a hidden form to http://localhost:3000/transfer.
Because sameSite is not set to Strict or Lax, the browser attaches the victim's session cookie to the cross-origin POST.

The victim's account is debited $500 and attacker receives it — without the victim's knowledge or consent.

Fix: add a random CSRF token to every state-changing form and validate it server-side, and/or set SameSite=Strict on the session cookie.
