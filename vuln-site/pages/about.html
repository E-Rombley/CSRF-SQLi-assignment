About VulnSite VulnSite is a deliberately vulnerable web application for security education. Demonstrated vulnerabilities: - SQL Injection (SQLi) and Blind SQLi - Cross-Site Scripting (XSS) — reflected and stored - Command Injection - Path Traversal - Local/Remote File Inclusion (LFI/RFI) - Cross-Site Request Forgery (CSRF) Each vulnerability is demonstrated at "low" security level (no defences).
